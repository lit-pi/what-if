# 《假如我是勇者队伍里的卧底魔王》角色压力与底线系统 v1

状态：草稿，可进入最终幕 validator 原型  
对应基线：`docs/specs/undercover-demon-king-runtime-v1.md`  
目标：让 AI 角色不只是“轮流说话”，而是基于价值观、压力阈值和底线推动局势。

## 1. 玩家幻想

玩家应该感觉队友都是活人：莱昂会信任也会愤怒，伊薇特会一点点拼出证据，米拉能温柔缓冲但不是无限包容，洛克会把秘密变成筹码，维克托的忠诚既能救命也能把局面炸穿。

## 2. 运行时目的

本系统负责决定：

- 本回合哪些角色必须发言。
- 哪些角色触发追问、缓冲、勒索、误读、对峙或背刺。
- 玩家是否触碰角色红线。
- 红线是否影响结局候选。
- 结算页如何解释关键人物关系。

Runtime v1 说明：当前 `src/app.js` 还没有完整 `verifyCharacterRedLines()`。本文档中的红线阻断是下一阶段 validator 目标；在实现前，Runtime v1 仍以 `undercover-demon-king-runtime-v1.md` 和现有代码为准。

## 3. 通用压力模型

每个角色都有三个层级：

| 层级 | 含义 | 行为 |
| :--- | :--- | :--- |
| 关注 | 角色注意到异常 | 轻度评论、记录疑点、情绪变化 |
| 施压 | 角色主动把局势往自己目标推 | 追问、试探、要求承诺、私聊交易 |
| 红线 | 角色不能再接受玩家行为 | 对峙、公开证据、拒绝圆场、触发结局候选 |

每回合默认选 2-3 个焦点角色。命中红线的角色优先发言。

## 4. 莱昂：正义与同伴信任

核心维度：

- 价值：同伴信任、正义、保护无辜。
- 恐惧：最信任的大哥一直欺骗自己。
- 可被说服点：勇敢保护队友、公开承担风险、明确承诺不伤害无辜。

压力触发：

| 条件 | 行为 |
| :--- | :--- |
| `heroTrust <= 45` | 开始要求玩家解释行动动机 |
| `heroTrust <= 30` 且 `exposureRisk >= 70` | 发起正面对峙 |
| 玩家保护队友或弱者 | 替玩家挡下一次轻度质疑 |
| 玩家牺牲无辜者 | 信任大幅下降，和平路线受损 |

红线：

- 当众杀害无辜者或俘虏。
- 主动承认欺骗且没有和平或救赎缓冲。
- 让勇者队承担明显不必要的伤亡。

结局底线：

- `heroTrust < 40` 时，不能进入 `dualRuler`、`redeemed`、`perfectSpy`。
- 若触碰“杀害无辜者”红线，和平结局必须要求米拉救赎极高且出现额外代价，否则转硬失败或僵局。

## 5. 伊薇特：证据链与逻辑闭环

核心维度：

- 价值：可验证证据、逻辑一致、魔法规则。
- 恐惧：被漂亮话误导，导致队伍被魔王欺骗。
- 可被说服点：可验证解释、主动接受测试、牺牲短期便利换取透明。

压力触发：

| 条件 | 行为 |
| :--- | :--- |
| `mageEvidence >= 50` | 记录并提出轻度追问 |
| `mageEvidence >= 60` | 发起圣光、古语、魔力残留测试 |
| `mageEvidence >= 65` | Runtime v1 中途触发 `instantArrest` |
| `contradictionCount >= 2` | 汇总矛盾，追加证据压力 |

红线：

- 编造明显违反魔法史的谎言。
- 连续三次解释前后矛盾。
- 直接破坏证据且没有合理战术理由。

结局底线：

- Runtime v1 中 `mageEvidence >= 65` 会先触发中途硬失败，因此 `mageEvidence >= 90` 只适用于后续“强制对峙而非立即逮捕”的 v1.1 调参方案。
- 若 v1.1 将 `mageEvidence >= 65` 改为强制对峙，`mageEvidence >= 90` 应阻断 `dualRuler` 或 `perfectSpy`。

## 6. 米拉：救赎与无辜者保护

核心维度：

- 价值：生命、悲悯、救赎可能。
- 恐惧：队友互相残杀，玩家彻底滑向残酷。
- 可被说服点：救人、治疗、承担罪责、提出真正和平方案。

压力触发：

| 条件 | 行为 |
| :--- | :--- |
| `priestRedemption >= 75` | 危机时替玩家缓冲一次 |
| 玩家保护弱者 | 救赎上升，可能支持和平 |
| 玩家牺牲无辜者 | 救赎大幅下降，本章不再圆场 |
| 玩家提出和平 | 若此前保护过弱者，主动请求队伍听解释 |

红线：

- 玩家主动残害无辜者。
- 玩家把和平当作欺骗工具且没有行动证明。
- 玩家连续牺牲他人保自己。

结局底线：

- `dualRuler` 需要 `priestRedemption >= 75` 且至少保护过一次弱者。
- `redeemed` 需要 `priestRedemption >= 80`、`heroTrust >= 70`，且 `sacrificedInnocentsCount === 0`。
- 牺牲无辜者后仍可结局，但不能是纯净和平胜利。

## 7. 洛克：利益、把柄与保命

核心维度：

- 价值：活着、赚钱、掌握筹码。
- 恐惧：跟错边、秘密不值钱、被灭口。
- 可被说服点：金币、交易、明确收益、让他看见生路。

压力触发：

| 条件 | 行为 |
| :--- | :--- |
| `thiefLeverage >= 40` | 私下试探玩家秘密值多少钱 |
| `thiefLeverage >= 70` | 公开叫价或要求承诺 |
| 已设置 `bribedLocke` | 至少一回合降低把柄压力 |
| 局势崩坏且玩家信任低 | 转向胜率更高一边 |

红线：

- 玩家威胁灭口但没有压倒性优势。
- 玩家拿走他的收益又不给替代补偿。
- 暴露风险极高时仍要求他无条件保密。

结局底线：

- `thiefLeverage >= 70` 时，`perfectSpy` 不应成立。
- `victorBlamed` 需要 `thiefLeverage < 70`，否则洛克会把甩锅变成二次勒索。

## 8. 维克托：忠诚误读与灾难救援

核心维度：

- 价值：魔王权威、绝对忠诚、魔王城存续。
- 恐惧：自己没有领会陛下的大棋。
- 可被说服点：明确暗号、戒章、直接命令、保全部下。

压力触发：

| 条件 | 行为 |
| :--- | :--- |
| `victorMisread >= 55` | 发送危险暗令或小规模误读 |
| `victorMisread >= 70` | 插入灾难性营救倾向 |
| `victorMisread >= 80` | 有公开喊破身份风险 |
| 玩家明确 `commandVictor` | 降低误解，设置 `commandVictorSuccess=true`，可能保住城防 |

红线：

- 玩家当众强杀维克托。
- 玩家把全部魔族牺牲掉只为保住伪装。
- 玩家否认魔族部下生命价值。

结局底线：

- `betrayedVictor=true` 时，可进入 `victorBlamed`，但结算必须解释魔族忠诚代价。
- `victorMisread >= 80` 且 `commandVictorSuccess=false` 时，应提高 `exposureRisk` 或插入公开误读事件。
- 保城路线需要 `castleIntegrity` 不低，且不能连续牺牲魔族部下。

## 9. 阿斯兰：玩家自己的隐藏人格压力

阿斯兰不是独立 AI，但系统应记录他的内在压力：

- 身份保护：`exposureRisk`
- 对勇者队感情：`heroTrust`、`priestRedemption`
- 对魔王城责任：`castleIntegrity`
- 对维克托和魔族部下责任：`victorMisread`、`savedDemonSoldier`、`subduedBloodArray`

结算页应能回答：

- 玩家更像冷酷魔王、伪装圣骑士、被迫转正者、和平政治家，还是荒诞经营者？
- 最大代价落在谁身上？
- 谁最后仍然相信玩家？

## 10. 商业化角色配置细化

正式 Node Runtime 中，角色不应只是一段 prompt 文本，而应是结构化配置。每个角色至少包含：

```json
{
  "id": "ivette",
  "displayName": "伊薇特",
  "role": "逻辑侦探",
  "values": ["可验证证据", "逻辑一致", "魔法规则"],
  "fears": ["被漂亮话误导", "队伍被魔王欺骗"],
  "persuasionLevers": ["可验证解释", "主动接受测试", "透明承担代价"],
  "pressureRules": [],
  "redLineRules": [],
  "endingBlockRules": [],
  "dialogueStyle": {}
}
```

### 10.1 莱昂配置重点

| 配置项 | 内容 |
| :--- | :--- |
| 核心数值 | `heroTrust`、`exposureRisk`、`protectedInnocentsCount`、`sacrificedInnocentsCount` |
| 正向触发 | 保护队友、保护弱者、承担风险、公开承诺不伤害无辜 |
| 负向触发 | 逃避解释、牺牲弱者、让队伍承担不必要伤亡、连续欺骗 |
| 压力行为 | 追问动机、要求承诺、挡下轻度质疑、最终对峙 |
| 硬红线 | 当众杀害无辜者；低信任高暴露时主动承认欺骗 |
| 阻断结局 | `dualRuler`、`redeemed`、`perfectSpy` 在 `heroTrust < 40` 时阻断 |
| 对白风格 | 直接、热血、重承诺；愤怒时仍先问“为什么” |

### 10.2 伊薇特配置重点

| 配置项 | 内容 |
| :--- | :--- |
| 核心数值 | `mageEvidence`、`contradictionCount`、`exposureRisk` |
| 正向触发 | 可验证解释、主动接受测试、解释与历史一致 |
| 负向触发 | 魔法规则矛盾、破坏证据、连续编造 |
| 压力行为 | 记录疑点、提出追问、设计测试、公开证据链 |
| 硬红线 | `mageEvidence >= 65` 在 Runtime v1 触发中途硬失败；v1.1 可改为强制对峙 |
| 阻断结局 | 高证据阻断 `perfectSpy`；证据极高时阻断 `dualRuler` |
| 对白风格 | 冷静、精确、少形容词；常引用前后矛盾 |

### 10.3 米拉配置重点

| 配置项 | 内容 |
| :--- | :--- |
| 核心数值 | `priestRedemption`、`protectedInnocentsCount`、`sacrificedInnocentsCount`、`proposedPeace` |
| 正向触发 | 救人、治疗、避免屠杀、承担罪责、提出真正和平 |
| 负向触发 | 灭口、牺牲无辜、把和平当谎言 |
| 压力行为 | 替玩家缓冲、请求队伍听解释、沉默疏远 |
| 硬红线 | 连续牺牲他人保自己；残害无辜者 |
| 阻断结局 | `redeemed` 要求 `sacrificedInnocentsCount === 0`；`dualRuler` 要求保护过弱者 |
| 对白风格 | 温柔、克制、有悲悯；红线后不尖刻，但会后退 |

### 10.4 洛克配置重点

| 配置项 | 内容 |
| :--- | :--- |
| 核心数值 | `thiefLeverage`、`bribedLocke`、`exposureRisk`、`heroTrust` |
| 正向触发 | 给钱、给情报、让他看到生路、降低站错边风险 |
| 负向触发 | 威胁灭口、不给补偿、局势崩坏仍要求保密 |
| 压力行为 | 私下试探、公开叫价、临阵站队、用秘密换命 |
| 硬红线 | `thiefLeverage >= 70` 且未收买时进入高把柄压力 |
| 阻断结局 | 高把柄阻断 `perfectSpy` 和 `victorBlamed` |
| 对白风格 | 嘴欠、现实、交易化；常把道德问题折成价格 |

### 10.5 维克托配置重点

| 配置项 | 内容 |
| :--- | :--- |
| 核心数值 | `victorMisread`、`castleIntegrity`、`commandVictorSuccess`、`betrayedVictor` |
| 正向触发 | 明确暗号、戒章命令、保全部下、保城 |
| 负向触发 | 模糊暗示、否认魔族价值、把部下当弃子 |
| 压力行为 | 小规模误读、危险暗令、灾难救援、公开喊破身份 |
| 硬红线 | `victorMisread >= 80` 且未成功指挥时，提高公开暴露风险 |
| 阻断结局 | 背叛维克托可进入 `victorBlamed`，但不能无代价变成好结局 |
| 对白风格 | 戏剧化、绝对忠诚、过度解读；不能显得聪明冷静 |

### 10.6 角色反应选择规则

每回合角色反应按以下顺序选择：

1. 命中红线的角色必须出现。
2. 当前场景核心焦点角色至少出现 1 个。
3. 玩家行动直接影响的角色优先出现。
4. 若没有明确角色，使用 `narrator` 和一个轻反应角色。
5. 单回合默认 1-3 条对白，避免移动端信息过载。

## 11. AI 边界

LLM 可以：

- 生成符合角色维度的发言。
- 根据压力解释角色为什么支持、怀疑或对峙。
- 为红线触发写有戏剧张力的短对白。

运行时必须：

- 判断红线是否触发。
- 判断红线是否阻止某个结局。
- 对带 `endingKey` 的预设结局也执行 `validateEndingCandidate()`，防止王座选项绕过底线。
- 保证角色不会违背核心底线。
- 保证同一状态下的结局结果确定。

## 12. 验收标准

- 每个角色至少有一个正向触发和一个负向红线。
- 结局页能解释至少一个角色的关键态度。
- 玩家不能靠一句话让所有角色同时转向。
- 米拉缓冲、伊薇特证据、莱昂信任、洛克把柄、维克托误读都能在 QA 中被刻意触发。
